Este repositorio contiene los diagramas interactivos generados para la documentación del sistema **Sigpaz**.

## 📄 Contenido
- **Diagrama de Casos de Uso:** Interacciones entre el usuario y el sistema.
- **Diagrama de Clases (UML):** Estructura completa de las entidades del sistema.
- **Esquema de la Base de Datos:** Estructura ordenada de las tablas.
- **Modelo Entidad-Relación (ER):** Relaciones entre las entidades de la base de datos.

## 🌐 Cómo visualizar los diagramas
Todos los diagramas están en formato HTML interactivo. Puedes verlos haciendo clic en los siguientes enlaces:

- 🔗 [Ver Diagrama de Casos de Uso](https://andrea-lopez-dev.github.io/docs/diagrams/DIAGRAMA_DE_CASOS_DE_USO.html)
- 🔗 [Ver Diagrama de Clases](https://andrea-lopez-dev.github.io/docs/diagrams/DIAGRAMA_DE_CLASES_COMPLETO.html)
- 🔗 [Ver Esquema de BD](https://andrea-lopez-dev.github.io/docs/diagrams/ESQUEMA_DE_LA_BD_ORDENADO.html)
- 🔗 [Ver Modelo ER](https://andrea-lopez-dev.github.io/docs/diagrams/MODELO_ER_ORDENADO.html)
