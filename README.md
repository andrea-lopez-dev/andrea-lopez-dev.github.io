## 📖 Descripción

Este repositorio contiene la documentación interactiva del sistema **SIGPAZ**. A través de una interfaz web moderna y responsiva con estilo **Glassmorphism**, podrás explorar los diferentes diagramas que componen la arquitectura del software y su base de datos, todo desde tu navegador sin necesidad de instalar nada.

<br>

Puedes explorar las versiones interactivas de todos los diagramas del sistema a través de tu sitio web en GitHub Pages:

🌐 **Visita la web de documentación:** [https://andrea-lopez-dev.github.io/](https://andrea-lopez-dev.github.io/)

Para acceder directamente a cada diagrama interactivo, haz clic en los siguientes enlaces:

- 🔗 [Clases UML (HTML interactivo)](//docs/diagrams/DIAGRAMA_DE_CASOS_DE_USO.html)
